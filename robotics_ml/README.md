# robotics_ml/

This folder tracks my ML-for-robotics learning and work, alongside the agentic AI and applied ML work in the rest of this repo.

## Focus

Applied ML in a robotics context — perception, control, and simulation, with an eye toward eventually connecting it to the agentic side of this repo (agents that plan/reason and hand off actions to a robotics control layer).

- Sensor data handling (vision, lidar, etc.)
- Control basics (feedback loops, PID)
- Perception models (object detection, pose estimation)
- Simulation environments (e.g. Gazebo, PyBullet, MuJoCo) before real hardware
- Robotics + agentic tie-in

## Structure

```
robotics_ml/
├── notebooks/    # hands-on practice and experiments
├── datasets/     # small datasets or scripts to fetch them
├── notes/        # concept notes as I learn
└── projects/     # end-to-end applied projects
```
