# notebooks/

This folder is for **exploratory, throwaway work** — the messy sandbox before anything becomes "real" code in `agents/` or `tools/`.

## What goes here

- Python fundamentals practice (functions, dicts/JSON, classes, error handling, async/await)
- Small experiments with the observe–think–act loop using stubbed/fake functions
- Quick tests of API calls, tool-calling responses, etc. before wiring them into a proper agent
- Anything you're still figuring out

## Guidelines

- No need for polish here — this is a learning and scratch space
- Name files descriptively by topic/date, e.g. `01_functions_practice.py`, `02_json_dicts.py`, `03_fake_agent_loop.py`
- Once something works and is worth keeping, "graduate" it into `agents/` or `tools/` properly
