# computer_vision/

This folder tracks my Computer Vision learning and work, alongside the agentic AI, applied ML, and robotics ML work in the rest of this repo.

## Focus

Practical computer vision, with an emphasis on edge deployment using an NVIDIA Jetson.

- Image processing fundamentals (OpenCV basics)
- Classic CV vs deep-learning-based CV
- Object detection, classification, segmentation
- Model optimization for edge inference (e.g. TensorRT) on Jetson
- Real-time inference from camera/video feeds
- CV + robotics tie-in (feeds into `robotics_ml/` for perception)
- CV + agentic tie-in (an agent using a vision model as a tool)

## Hardware

- **NVIDIA Jetson** — edge deployment and real-time inference target
