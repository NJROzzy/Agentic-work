# ml/

This folder tracks my applied ML learning and work, alongside the agentic AI projects in the rest of this repo.

## Focus

Applied ML — using ML to solve real, practical problems, rather than building algorithms from first principles. Emphasis on:

- Working with real datasets (cleaning, wrangling, prep)
- Using pre-trained models and ML APIs where practical
- Training and evaluating models for actual problems
- Eventually: tying ML outputs into agent tools (e.g., an agent that calls a classifier or predictive model as one of its tools)

## Structure

```
ml/
├── notebooks/    # hands-on practice and experiments
├── datasets/     # small datasets or scripts to fetch them
├── notes/        # concept notes as I learn
└── projects/     # end-to-end applied projects
```
